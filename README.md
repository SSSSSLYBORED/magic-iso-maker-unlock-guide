## 📚 Function Index

| Function Name           | Description                                                                                                              |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------|
| `autoDetectISOFormat()` | Scans and displays details about your ISO/disc images instantly, recognizing over 15 formats.                           |
| `smartMountDrive()`     | Mounts any supported image file virtually, with performance optimization powered by AI suggestions.                      |
| `aiSuggestRoutine()`    | Uses OpenAI or Claude to propose workflows, startup tasks, and image handling routines based on recent user patterns.    |
| `localizeUI(lang)`      | Switches the entire interface to any supported language instantly.                                                      |
| `secureExtract(folder)` | Securely extracts files, performing integrity scans and threat assessments.                                             |
| `batchConvert(images)`  | Converts multiple disc image files to your chosen format in one streamlined batch process.                              |
| `liveSupport(contact)`  | Connects you with a support specialist or AI helper any time, day or night.                                             |
